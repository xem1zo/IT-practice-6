# Лабораторная работа №6: Нормализация данных в БД (вариант 2)

## 🎯 Цель работы
Привести «плохую» таблицу `sales_unnormalized` к Третьей нормальной форме (3NF), разбив её на 4 таблицы (`clients`, `products`, `sales`, `sale_items`).

## ⚙️ Выполненные шаги
1. Создана база данных `sales_norm` и исходная таблица `sales_unnormalized`.
2. Созданы 4 нормализованные таблицы.
3. Данные перенесены с помощью `INSERT ... SELECT`.
4. Проверено, что общая сумма (`SUM(unit_price * quantity)`) до и после совпадает.
5. Создан дамп базы `dump_clean.sql` и лог `my_actions.log`.
